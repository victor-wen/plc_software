# 操作员手册

本上位机用于 Windows 工控机，通过 Modbus RTU 与汇川 H3U PLC 通信。当前版本默认以**模拟模式**运行（没有真实 PLC），详见 `docs/simulation-guide.md`。本手册介绍正常操作流程。

> 安全原则：PLC 始终负责自动流程、输出执行和安全联锁。上位机只读取状态并**提交请求**，不替代物理急停、安全门、光栅、气压检测或 PLC 内部保护。任何联锁的最终判定由 PLC 完成。

---

## 1. 启动应用

- 双击 `PlcSoftware.App.exe`（或发布后的入口程序）启动。
- 应用为**单实例**限制：同一时刻只允许一个进程运行，避免两个进程争用同一串口。第二实例会自动退出。
- 默认以**模拟模式**启动（`InMemoryModbusClient` + 模拟场景），可直接看到流程在自动运行，无需连接真实 PLC。
- 连接失败时状态栏显示断线，画面仍可打开并查看最后快照（见 §7 断线行为）。

## 2. 主界面导航

主窗口左侧为导航，右侧为对应页面：

| 导航项 | 页面 | 功能 |
|---|---|---|
| 总览 | `OverviewView` | 显示等待进板 / 进料 / 挡停定位 / 触发相机 / 请求放行 / 放行流程，高亮当前步骤，并显示传感器、挡停、当前/目标宽度、皮带速度与产量。 |
| 操作 | `OperationView` | 启动、停止、复位、急停请求、自动 / 手动 / 直通模式。 |
| 手动 | `ManualView` | 调宽正反转、皮带点动、挡停（按住执行）。 |
| 参数 | `ParametersView` | 编辑 D201 / D202 / D204 / D205，显示 D203 / D210 / D212-D213。 |
| I-O 诊断 | `IoDiagnosticsView` | 按 X / Y / M 分组只读显示逻辑状态与中文名称。 |
| 通信设置 | `ConnectionSettingsView` | 配置串口与站号、枚举串口、连接测试。 |
| 报警与历史 | `HistoryView` | 按日期查询报警与操作审计，支持 CSV 导出。 |
| 调试终端 | `DiagnosticTerminalView` | 结构化 Modbus 读写（FC01-04 读，FC05-06 写）。 |

全局状态栏（每页顶部）显示：串口状态、PLC 心跳、当前模式、运行状态、总故障、屏蔽状态和当前时间。断线 / 故障 / 屏蔽会同时用颜色、文字和图标提示。

## 3. 模式切换规则

上位机通过写 `M104` / `M105` 请求模式，采用互斥组合：

| 目标模式 | 上位机写入 | PLC 返回为手动 | PLC 运行状态 |
|---|---|---|---|
| 手动 | `M104=0, M105=0` | `M1=1` | 非运行 |
| 自动 | `M104=1, M105=0` | `M2=1` | 允许运行 |
| 直通 | `M104=0, M105=1` | `M13=1` | 允许运行 |

> **重要**：界面必须等待 PLC 通过 `M1` / `M2` / `M13` **回读确认最终模式**，不得仅以上位机按钮写入结果作为切换成功依据。写入后如未见 PLC 返回对应模式，模式不生效。

## 4. 急停请求

- 界面上的“急停请求”是**软件请求**（上位机写 `M100`，约 200 ms 脉冲），由 PLC 执行联锁与停机，**不是物理急停**。
- 物理急停以设备上的物理按钮为准；上位机的急停请求只读 `M0`（急停有效）反映其状态。
- 发生真实安全事件时，请直接按下物理急停并立即停止使用本机。

## 5. 参数页写入

参数页可编辑：`D201` 调宽速度（Hz）、`D202` 目标宽度（mm）、`D204` 脉冲当量（脉冲/mm）、`D205` 皮带速度（Hz）。

- 写入前显示旧值、新值、单位和允许范围。
- 写入后必须读回一致才报告成功；写回失败时保留原值并记录原因。
- 参数上下限来自配置，越界或未配置/非法范围时禁止写入。
- 断线时写入按钮被禁用（见 §7）。

## 6. 调试终端

调试终端支持 `FC01 / FC02 / FC03 / FC04` 结构化读取，以及 `FC05 / FC06` 单点写入。输入站号、零基协议地址、数量或值，显示请求摘要、响应、耗时、异常码和十六进制数据。

- **只读默认允许**；**写入受控**：需先**解锁**，且仅在设备**非运行**时允许。
- 写入每次需**确认**，解锁**5 分钟无操作自动锁定**。
- 终端命令进入统一请求队列并记录审计日志。
- **不提供任意原始 RTU 帧发送**，也不提供 I/O 表的任意强制写入入口（手动动作只能通过“手动”页执行）。

## 7. 断线行为

连续 3 次请求失败后进入断线状态（连接状态含：断开、连接中、在线、PLC 心跳异常、重连中）。

- 断线时**冻结最后快照**，界面显示最后更新时间戳。
- 状态变灰，表示数据不再刷新。
- **全部写操作被禁用**（启动、停止、模式、手动点动、参数写入、屏蔽等）。
- 重连退避：1、2、5、10、30 秒，之后保持 30 秒间隔。重连后只恢复轮询与 `D106` 看门狗，**不重放未完成的命令**。
- 脉冲写入超时视为结果未知，程序读取状态核对，不盲目重复启动或复位。

## 8. 单实例与日志

- **单实例限制**：同一串口只允许一个进程独占；第二实例启动即退出。
- **崩溃日志**：应用异常退出时，诊断信息（时间戳 / 类型 / 消息 / 堆栈）写入 `logs/crash-yyyyMMdd-HHmmssff.log`。日志目录相对运行目录，即发布目录下的 `logs/`。
- 历史数据写入 `data/history.db`（SQLite），保留一年（见 `docs/configuration.md`）。

## 9. 停止应用

- 正常关闭窗口即可；退出时上位机尝试复位所有保持中的点动命令（`M106-M109`），并以最佳努力停止后台服务。
- 在线时约每 200 ms 刷新 `D106` 看门狗；PLC 若约 500 ms 未检测到 `D106` 变化，会清除手动输出并禁止手动命令，直到通信恢复且操作员重新按下。
- 应用启动时**不恢复**任何保持命令或屏蔽状态。
